# ELTE Computer Science — Coursework Repository

Ez a tároló az Eötvös Loránd Tudományegyetem Informatikai Karán (ELTE IK) Programtervező informatikus képzés során készített gyakorlati feladataimat, kurzusbeadandóimat és szakmai projektjeimet foglalja össze egy helyen.

---

## Ebben a tárolóban archivált projektek

### 1. [Webfejlesztés 1 — Magyar CS e-sport Honlap](./Web%201%20-%20Beadando/)
* **Technológiák:** HTML5, CSS3, Bootstrap 5, JavaScript
* **Főbb funkciók:** 5 aloldalból álló, szemantikus és reszponzív weboldal a hazai Counter-Strike történetéről és nemzetközi sikereiről (torzsi, sl3nd, MOUZ).
* **Akadálymentesítés & szabványok:** Különálló nyomtatási stíluslap (`print.css`), dinamikus betűméretező `localStorage` perzisztenciával, nagy kontrasztú megjelenítési mód, skip-link és WCAG 2.0 irányelveknek megfelelő űrlap.

### 2. [Webfejlesztés 2 (Kliensoldal) — PartyZone JS Admin](./Web%202%20-%20JS%20beadando/)
* **Technológiák:** Natív JavaScript (Vanilla JS ES6+), HTML5, CSS3
* **Főbb funkciók:** Egyoldalas (SPA) adminisztrációs felület celebek, platformok és kategóriák kezelésére lapfüles nézetben.
* **Bónusz megoldások (+10 pont):** Relációs integritást ellenőrző törlési logika, kattintásos gyorsszűrés címkékre, oszlopfejlécre kattintva háromállapotú rendezhető statisztikai diagramok és teljes körű `localStorage` adatmegőrzés.

### 3. [Webfejlesztés 2 (Szerveroldal) — PartyZone PHP Admin](./Web%202%20-%20PHP%20beadando/)
* **Technológiák:** Natív PHP 8, JSON Storage (`Storage` & `JsonIO` minta), HTML5, CSS3
* **Főbb funkciók:** Szerveroldali architektúra szerepkör-alapú jogosultságkezeléssel (Guest, User, Admin) és biztonságos bcrypt jelszóhasheléssel (`password_hash`).
* **Bónusz megoldások (+11 pont):** Dedikált beépített admin fiók, integritásvizsgáló platformtörlés, szerzői azonosítón (`created_by`) alapuló celebtörlés, kattintásos címkeszűrés és UTF-8 ékezetes keresés.

## További kiemelt kurzus- és szakmai projektek (Külön tárolókban)

* **[DrunkYard-MAUI](https://github.com/Benceee999/DrunkYard-MAUI)**  
  Többrétegű MVVM architektúrára épülő, keresztplatformos mobilalkalmazás .NET 10 MAUI-ban. Offline-first működés helyi SQLite adatbázissal, hardveres gyorsulásmérő (shake detection) és haptikus visszajelzés, felhőszinkronizáció és közösségi játékszavazás REST API-n keresztül.

* **[Vernyomasnaplo-ASP.NET](https://github.com/Benceee999/Vernyomasnaplo-ASP.NET)**  
  Egészségügyi mérési napló webalkalmazás ASP.NET Core Razor Pages keretrendszerben. Entity Framework Core perzisztencia, interaktív Chart.js diagramok a vérnyomásértékek vizualizációjára és XML formátumú adatmentés/exportálás.

* **[Regisegbolt-Django](https://github.com/Benceee999/Regisegbolt-Django)**  
  Teljes értékű online régiség- és aukciós portál Django 5 keretrendszerben. Szerveroldali lapozás, dinamikus licitálási logika, aukcióvezetői adminisztrációs felület, automatikus adatbázis-feltöltő szkriptek és átfogó egységtesztek.
